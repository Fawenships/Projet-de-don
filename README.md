# Projet-de-don
🤝 Collecteur de Dons — README

📌 Présentation

Collecteur de Dons est une plateforme destinée à aider les personnes en difficulté en Haïti, notamment celles confrontées à la maladie, à la pauvreté ou à d'autres situations nécessitant une aide financière.

La plateforme permet aux personnes ayant besoin d'aide de créer un profil présentant leur situation. Les donneurs peuvent ensuite consulter les différents profils et envoyer directement une contribution à la personne de leur choix.

🎯 Objectif du projet

L'objectif est de créer un système simple, accessible et transparent permettant de :

- 🧑‍🤝‍🧑 Mettre en relation les personnes dans le besoin avec les donneurs.
- 💰 Faciliter les petits dons à partir de 15 HTG.
- 📱 Permettre les paiements via MonCash et NatCash.
- 🔎 Classer les demandes par catégorie.
- 📄 Présenter clairement la situation de chaque bénéficiaire.
- 🛡️ Mettre en place un système de vérification pour limiter les fausses demandes.

👤 Inscription des bénéficiaires

Une personne qui souhaite recevoir de l'aide pourra créer une demande en fournissant notamment :

- Nom et prénom
- Photo
- Numéro de téléphone
- Numéro MonCash ou NatCash
- Pièce d'identité pour vérification
- Catégorie de la demande
- Description détaillée de sa situation
- Montant ou objectif d'aide souhaité

📂 Catégories possibles

Les demandes pourront être classées par exemple en :

- 🏥 Maladie / Santé
- 🍚 Pauvreté / Alimentation
- 🏠 Logement
- 🎓 Éducation
- 👨‍👩‍👧 Famille
- 🚨 Situation urgente
- 📌 Autres besoins

💝 Pour les donneurs

Les donneurs pourront :

1. Visiter le site.
2. Consulter les différentes demandes.
3. Choisir une personne à aider.
4. Consulter sa description et sa catégorie.
5. Choisir le montant du don.
6. Envoyer directement l'argent via MonCash ou NatCash.

Le montant minimum prévu pour un don est de 15 HTG.

💸 Exemple

«Une personne a besoin d'aide pour payer des frais médicaux.»

Elle crée une demande avec sa photo, sa pièce d'identité, son numéro de paiement et une description de sa situation.

Un donneur consulte son profil et décide de lui envoyer 15 HTG, 50 HTG, 100 HTG ou plus directement sur le moyen de paiement indiqué.

🔐 Sécurité et vérification

La confiance est essentielle pour ce projet.

La plateforme devra prévoir :

- Vérification de l'identité des bénéficiaires.
- Protection des informations personnelles.
- Vérification des demandes avant leur publication.
- Système permettant de signaler une demande suspecte.
- Protection contre les faux comptes et les fraudes.
- Limitation de l'affichage public des informations sensibles.

Important : une pièce d'identité contient des informations personnelles sensibles. Elle ne devrait pas être affichée publiquement sur le profil ; elle devrait être utilisée uniquement pour la vérification.

🛠️ Fonctionnalités principales

Pour les bénéficiaires

- Création de compte
- Création d'une demande d'aide
- Ajout d'une photo
- Ajout de documents pour vérification
- Choix d'une catégorie
- Description du besoin
- Ajout du moyen de paiement
- Suivi des dons reçus

Pour les donneurs

- Consultation des demandes
- Recherche par catégorie
- Consultation d'un profil
- Choix du montant
- Don via MonCash ou NatCash
- Possibilité de soutenir plusieurs personnes

Pour l'administration

- Tableau de bord
- Vérification des bénéficiaires
- Validation ou refus des demandes
- Gestion des comptes
- Gestion des catégories
- Signalement des fraudes
- Suivi des dons
- Modération du contenu

💳 Paiements

Le projet prévoit l'intégration de :

- MonCash
- NatCash

L'intégration devra utiliser les solutions/API officielles ou un prestataire de paiement autorisé, afin de garantir la sécurité des transactions.

🌐 Technologies

Les technologies pourront être adaptées selon l'évolution du projet.

Exemple :

- Frontend : HTML, CSS, JavaScript
- Backend : Node.js / PHP / autre
- Base de données : MySQL / PostgreSQL
- Hébergement : à définir
- Paiements : MonCash + NatCash
- Authentification : système sécurisé de comptes utilisateurs

🚀 Vision du projet

L'objectif à long terme est de créer une plateforme haïtienne fiable permettant à chacun de contribuer, même avec une petite somme.

«Un petit don peut faire une grande différence. ❤️🇭🇹»
